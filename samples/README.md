# 示例音频（samples）

这些文件用来**快速验证**程序是否正常工作，也可以用来熟悉三种典型场景。
全部为 16 kHz 单声道 WAV，可直接拖进主界面解码。

---

## 1. `sample_cq.wav` — 干净信号（基准）

```
内容：CQ CQ DE BD6LBA K
参数：20 WPM / 700 Hz / 无噪声
```

**预期结果**

| 后端 | 结果 |
|---|---|
| DSP | `CQ CQ DE BD6LBA K` |
| CTC | `CQ CQ DE BD6LBA K` |

**用途**：如果你的程序解不出这一段，说明环境有问题（设备/音频增强/路径），先别怀疑算法。

---

## 2. `sample_multi_freq.wav` — 换台（QSY）

```
内容：同一句报文连发三次，频率依次 700 → 1000 → 700 Hz
参数：20 WPM，每段之间留 1.2 秒静音
```

**预期结果**

| 场景 | 结果 |
|---|---|
| 文件模式（DSP，锁定单一音调） | 只能解出 700 Hz 的那两段 |
| 实时模式 + 勾选「跟随频率」 | **三段都能解出来**，文本形如 `CQ CQ DE BD6LBA K  CQ CQ DE BD6LBA K  CQ CQ DE BD6LBA K` |
| 实时模式 + 不勾选「跟随频率」 | 只解第一段，之后没有新文本 |

**用途**：验证「跟随换台」功能；也说明为什么文件模式适合单台、实时模式适合追台。

---

## 3. `sample_noisy.wav` — 噪声 + 工频

```
内容：CQ CQ DE BD6LBA K
参数：20 WPM / 600 Hz / 8 dB 噪声 / 叠加 50 Hz 与 100 Hz 工频
```

**预期结果**

| 后端 | 结果 |
|---|---|
| DSP | 通常仍为 `CQ CQ DE BD6LBA K` |
| CTC | 同上 |

**用途**：模拟麦克风环境（房间嗡声、底噪），验证降噪与门限的鲁棒性。

---

## 4. `sample_two_stations.wav` — 两个信号同时存在

```
内容：700 Hz 发送 "CQ CQ DE BD6LBA K"
      1000 Hz 同时发送 "TEST TEST DE R3ABC"
```

**预期结果**

| 场景 | 结果 |
|---|---|
| 多频道扫描 | 列表中应出现 **700 Hz** 与 **1000 Hz** 两个频道 |
| 选中 700 Hz 解码 | `CQ CQ DE BD6LBA K` |
| 选中 1000 Hz 解码 | `TEST TEST DE R3ABC` |

**用途**：验证多频道发现与「点频道换台」；也说明同频重叠信号无法分离（这两个不同频，所以可以）。

---

## 自己生成测试音频

程序内置「发送练习」窗口（工具栏 → 发送练习），可以：

```
· 选模板（CQ / RST / 73 / 俄文问候 …）
· 调速度 5–40 WPM、音调 500–1000 Hz
· 试听、保存为 WAV
```

生成的音频可以直接拖回主界面解码，用来验证「已知内容 → 解码 → 对照」。
