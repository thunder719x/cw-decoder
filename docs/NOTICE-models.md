## models/ctc/acoustic.onnx

```
用途：CTC 后端（弱信号 / QSB 衰落场景）的声学模型
体积：约 4.3 MB
输入：11 维声学特征（AGC 包络 + 导数 + 9 个谱 bin），200 帧/秒
输出：65 个 token 的概率（含 blank）
来源：第三方 CTC 声学模型（morsedesk 项目的 acoustic 模型）
```

**如果要替换/重新训练**

```
· 输入特征与词表定义见 cwdec/ctc.py 与 models/ctc/acoustic.json
· 只要保持 11 维特征与 65 token 词表，可直接替换 onnx 文件
· 也可以只用 DSP 后端（不加载模型，功能除弱信号外不受影响）
```
